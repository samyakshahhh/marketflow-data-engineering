# Developer memory

One file per developer: `<git-user-name-lowercase-hyphenated>.md`, created from
[`../../templates/memory_template.md`](../../templates/memory_template.md) the
first time that developer confirms a persistent preference.

Rules (full version in [`../README.md`](../README.md)):

- Save only explicit or confirmed preferences.
- No secrets, credentials or personal contact details.
- A preference never overrides security rules, the current request, Jira
  acceptance criteria or established project conventions.
